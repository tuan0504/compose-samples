Each phase draws from these apps — knowing what each one demonstrates helps you navigate the guides.

App Complexity Best For Learning

Jetsnack Intermediate Custom design system, gradient Modifiers, component library pattern

JetNews Intermediate Navigation 3 (experimental), TestAppContainer, snapshotFlow testing
Jetcaster Advanced Multi-form-factor (mobile + TV + Wear), dynamic theming, 7-flow combine, UseCase unit tests

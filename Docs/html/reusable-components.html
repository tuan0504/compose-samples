Modifier Extensions

Drop-in Modifier functions — copy to any project with zero dependencies beyond Compose.

verticalGradientScrim Modifier

From Jetcaster mobile/util/GradientScrim.kt. Draws a vertical gradient overlay over any content — used for image overlays so text remains readable over artwork.

Kotlin — GradientScrim.kt 
fun Modifier.verticalGradientScrim(
    color: Color,
    startYPercentage: Float = 0f,   // 0f = top of element
    endYPercentage: Float = 1f,     // 1f = bottom
    decay: Float = 1.0f,            // 1f = linear, >1f = slower fade at start
    numStops: Int = 16,             // quality vs performance
): Modifier

fun Modifier.radialGradientScrim(color: Color): Modifier

// Usage — fade image to black at the bottom
Box(modifier = Modifier.fillMaxSize()) {
    Image(...)
    Box(
        modifier = Modifier
            .fillMaxSize()
            .verticalGradientScrim(
                color = Color.Black,
                startYPercentage = 0.3f,
                endYPercentage = 1f,
                decay = 3f,
            )
    )
    Text(modifier = Modifier.align(Alignment.BottomStart), ...)
}

ModifierNodeElement

Uses the modern API — not the deprecated drawWithContent. Exposed in Layout Inspector via inspectableProperties().

Non-linear decay

Exponential stop calculation — decay = 3f makes the fade slow at start, accelerating toward the bottom. Pure linear looks unnatural on photos.

Composables

Ready-to-adapt composables for common screen needs.

PodcastImage — async image with all states Composable

From Jetcaster core/designsystem/component/PodcastImage.kt. The standard pattern for any async image that needs: preview support, loading state, error fallback.

Kotlin — PodcastImage.kt 
@Composable
fun PodcastImage(
    podcastImageUrl: String,
    contentDescription: String?,
    modifier: Modifier = Modifier,
    contentScale: ContentScale = ContentScale.Crop,
    placeholderBrush: Brush = thumbnailPlaceholderDefaultBrush(),
) {
    // 1. Short-circuit in Compose Preview — no network, no crash
    if (LocalInspectionMode.current) {
        Box(modifier = modifier.background(MaterialTheme.colorScheme.primary))
        return
    }

    var imagePainterState by remember {
        mutableStateOf<AsyncImagePainter.State>(AsyncImagePainter.State.Empty)
    }

    val imageLoader = rememberAsyncImagePainter(
        model = ImageRequest.Builder(LocalContext.current)
            .data(podcastImageUrl)
            .crossfade(true)
            .build(),
        contentScale = contentScale,
        onState = { state -> imagePainterState = state },
    )

    Box(modifier = modifier, contentAlignment = Alignment.Center) {
        // 2. Loading / Error → show placeholder brush (shimmer or solid)
        when (imagePainterState) {
            is AsyncImagePainter.State.Loading,
            is AsyncImagePainter.State.Error ->
                Image(painter = painterResource(R.drawable.img_empty), ...)
            else -> Box(modifier = modifier.background(placeholderBrush).fillMaxSize())
        }
        // 3. Always render (Coil handles the crossfade transition)
        Image(painter = imageLoader, contentDescription = contentDescription, ...)
    }
}
Adapt to your project

Replace R.drawable.img_empty with your placeholder. Replace thumbnailPlaceholderDefaultBrush() with a shimmer brush or solid color.

fun AnimatingFabContent(

) {
    Row(modifier = modifier) {

Preview Annotations

Copy MultipreviewAnnotations.kt directly from JetNews — no modifications needed.

MultipreviewAnnotations.kt Annotation

Eliminates writing 3 separate @Preview annotations on every composable. One annotation generates previews for dark mode, small font, large font, phone, foldable, and tablet.

Kotlin — MultipreviewAnnotations.kt (JetNews) 
@Preview(name = "phone",    device = "spec:width=360dp,height=640dp,dpi=480")
@Preview(name = "foldable", device = "spec:width=673dp,height=841dp,dpi=480")
@Preview(name = "tablet",   device = "spec:width=1280dp,height=800dp,dpi=480")
annotation class DevicePreviews

@Preview(name = "small font", fontScale = 0.5f)
@Preview(name = "large font", fontScale = 1.5f)
annotation class FontScalePreviews

@Preview(name = "dark theme", uiMode = UI_MODE_NIGHT_YES)
@FontScalePreviews
@DevicePreviews
annotation class CompletePreviews

// Usage — one annotation instead of many
@CompletePreviews
@Composable
private fun MyScreenPreview() {
    MyTheme { MyScreen() }
}

Navigation Utilities

Copy these patterns into any project that uses NavController.

lifecycleIsResumed() guard Pattern

Kotlin 
private fun NavBackStackEntry.lifecycleIsResumed() =
    this.lifecycle.currentState == Lifecycle.State.RESUMED

// In composable — guard every navigation callback
JetsnackButton(
    onClick = {
        if (backStackEntry.lifecycleIsResumed()) {
            navController.navigate(route)
        }
    }
)

rememberAppState pattern Pattern

Wrap NavController in a @Stable class so composables don't hold direct controller references.

Kotlin 
@Stable
class MyAppState(val navController: NavHostController) {
    fun navigateToDetail(id: Long, from: NavBackStackEntry) {
        if (from.lifecycleIsResumed()) {
            navController.navigate(DetailRoute(id))
        }
    }
    fun navigateBack() { navController.popBackStack() }
}

@Composable
fun rememberMyAppState(navController: NavHostController = rememberNavController()) =
    remember(navController) { MyAppState(navController) }

Patterns that prevent recomposition bugs and keep ViewModels testable.

_state.value = _state.value.copy(

Sealed Action interface Pattern

One entry point for all user events — easier to test and trace. Add one entry per user action.

Kotlin 
sealed interface MyScreenAction {
    data class  ItemClicked(val id: Long) : MyScreenAction
    data object RefreshRequested              : MyScreenAction
    data class  SearchQueryChanged(val query: String) : MyScreenAction
}

// ViewModel — single dispatch
fun onAction(action: MyScreenAction) {
    when (action) {
        is MyScreenAction.ItemClicked        -> openDetail(action.id)
        is MyScreenAction.RefreshRequested   -> refresh()
        is MyScreenAction.SearchQueryChanged -> updateSearch(action.query)
    }
}

// Composable — single callback parameter
MyScreenContent(
    uiState = uiState,
    onAction = viewModel::onAction,
)

Internal ViewModelState → sealed public UiState Pattern

From JetNews. The internal class is easy to .copy(); the public sealed type gives the UI compile-time safety.

Kotlin 
private data class MyViewModelState(
    val data: List<Item>? = null,
    val isLoading: Boolean = false,
    val error: String? = null,
) {
    fun toUiState(): MyUiState = when {
        data == null && isLoading     -> MyUiState.Loading
        data == null && error != null -> MyUiState.Error(error)
        data != null                  -> MyUiState.Success(data)
        else                          -> MyUiState.Loading
    }
}

sealed interface MyUiState {
    data object Loading                         : MyUiState
    data class  Error(val message: String)      : MyUiState
    data class  Success(val data: List<Item>)   : MyUiState  // non-null guaranteed
}

val uiState = viewModelState
    .map(MyViewModelState::toUiState)
    .stateIn(viewModelScope, SharingStarted.Eagerly, viewModelState.value.toUiState())

File Why to skip
